# Noor Fatima - Portfolio Website 🌸

A modern, fully responsive personal portfolio website built to showcase my journey as a Full Stack Developer and AI enthusiast. 

##  Live Demo
Check out the live site here: **[https://portfolio-inky-theta-69.vercel.app](https://portfolio-inky-theta-69.vercel.app)**

## ✨ Features
- **Modern UI/UX:** Clean lavender and red theme with smooth scroll animations.
- **Responsive Design:** Looks great on mobile, tablet, and desktop.
- **Project Showcase:** Detailed breakdowns of my university projects (Stress Analyzer, Log Processing, E-commerce).
- **Certifications:** A dedicated section highlighting my continuous learning in AI, Cloud, and Web Dev.
- **Working Contact Form:** Integrated with Formspree for real-time message delivery.

## 🛠️ Technologies Used
- HTML5, CSS3, JavaScript
- Font Awesome (for icons)
- Vercel (for deployment)

##  Project Structure
- `index.html`: Main structure of the website.
- `style.css`: All styling, animations, and responsive media queries.
- `script.js`: Form handling, scroll animations, and interactive logic.
- `assets/`: Contains profile picture, project screenshots, and certificate images.

## 🚀 How to Run Locally
1. Clone this repository: `git clone https://github.com/NUR0710/Portfolio.git`
2. Open the `index.html` file in your web browser.
